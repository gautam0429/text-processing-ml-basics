# NLP Summarization and Sentiment API

A practical collection of examples covering Transformer-based text summarization, sentiment model deployment with FastAPI, and troubleshooting of conversational AI intent classification.

## Features

- Transformer-based text summarization approach
- FastAPI REST API for sentiment prediction
- JSON request and response handling
- Conversational AI troubleshooting approach
- Basic NLP and machine learning concepts

## Tech Stack

- **Python** - Programming language
- **FastAPI** - REST API framework
- **Uvicorn** - ASGI server for running the FastAPI application
- **Pydantic** - Request data validation
- **Hugging Face Transformers** - Transformer-based NLP models
- **Natural Language Processing (NLP)** - Text processing and understanding
- **Machine Learning** - Text classification and sentiment analysis
